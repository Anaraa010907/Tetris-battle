# Neon Duel: Supabase холболт

Тоглоом Supabase-гүйгээр бүрэн офлайн ажиллана. Доорх тохиргоог хийсний дараа онлайн болно: бүртгэл, сервер дээр тооцогдох rank, тэргүүлэгчдийн жагсаалт, ижил цолтой тоглогчтой онлайн 1v1 rank тоглолт.

Серверийн SQL болон тоглоомын онлайн хэсгийг энгийн Postgres ба Supabase Realtime-ийг орлуулсан туршилтын орчинд хоёр тоглогчоор шалгасан. Жинхэнэ Supabase project дээр хараахан туршаагүй тул холбосны дараа хоёр утсаар нэг тоглолт хийж шалгана уу.

## 1. Project үүсгэх

1. https://supabase.com дээр **New project** үүсгэнэ. Region-оо Монголд ойр **Northeast Asia (Seoul)** эсвэл **Tokyo** гэж сонгоно.
2. **SQL Editor → New query** нээгээд `supabase/migrations` хавтсан дахь хоёр файлыг **нэрийн дарааллаар нь** тус тусад нь хуулж **Run** дарна:
   1. `20261113000000_neon_duel_init.sql`
   2. `20261115000000_ranked_online.sql`

   Supabase CLI ашигладаг бол `supabase db push` хийнэ. Дахин ажиллуулах бол хоёуланг нь мөн энэ дарааллаар ажиллуулна.

## 2. Нэвтрэлтийн тохиргоо (Authentication)

- **Sign In / Providers → Anonymous sign-ins**-ийг асаана. Тоглоом анх нээгдэхэд тоглогч бүрт автоматаар зочин бүртгэл үүсгэдэг.
- **Email** provider асаалттай байх ёстой. Тоглогч "Бүртгэлээ хамгаалах" дарж имэйл, нууц үгээ холбоход хэрэглэгдэнэ.
  - **Confirm email** асаалттай бол баталгаажуулах имэйл очно. Туршилтын үед унтрааж болно, тоглоом гаргахын өмнө асаана.
- Зочин бүртгэлийг урвуулан ашиглахаас сэргийлэхийн тулд хожим **Attack Protection**-оос CAPTCHA (Turnstile) асаахыг зөвлөж байна.

## 3. Realtime

Онлайн тоглолтын үед хоёр утас Realtime **Broadcast** сувгаар (`match:<id>`) мэдээлэл солилцоно. Нэмэлт тохиргоо шаардахгүй: суваг нь public бөгөөд дугаарыг нь зөвхөн тухайн хоёр тоглогч мэднэ. Realtime-ийн тохиргоонд public сувгийг хориглосон бол (анхдагчаар зөвшөөрөгдсөн байдаг) буцааж зөвшөөрнө.

Мессежийн зарцуулалтыг багасгахын тулд тоглоом блок тавих бүрд нэг, чимээгүй үед секундэд нэг мессеж илгээдэг (тоглогч бүр секундэд 1–2 орчим).

## 4. Тоглоомд түлхүүрээ оруулах

**Project Settings → API** хэсгээс **Project URL** болон **anon (publishable) key**-г авна. Anon key-г тоглоомд оруулахад аюулгүй: бүх хүснэгт RLS-ээр хамгаалагдсан, оноо болон зоосыг зөвхөн серверийн функцүүд өөрчилдөг.

- **APK-д (санал болгох):** GitHub repo → **Settings → Secrets and variables → Actions** хэсэгт `SUPABASE_URL` болон `SUPABASE_ANON_KEY` гэсэн хоёр secret нэмнэ. Дараагийн APK build автоматаар онлайн хувилбар болно. Secret байхгүй бол офлайн хувилбар гарна.
- **Вэб хувилбарт:** `index.html` доторх `<script id="neon-config">` блокийг бөглөнө:
  ```html
  <script id="neon-config" type="application/json">{"supabaseUrl":"https://xxxx.supabase.co","supabaseAnonKey":"eyJ..."}</script>
  ```

Өөрийн домэйн (custom domain) ашиглавал `index.html`-ийн толгой дахь `Content-Security-Policy`-ийн `connect-src`-д тэр домэйноо нэмнэ. Одоо `https://*.supabase.co wss://*.supabase.co` байгаа.

## 5. Онлайн болоход юу ажиллах вэ

| Хэсэг | Хэрхэн |
| --- | --- |
| Бүртгэл | Анх нээхэд зочин бүртгэл үүснэ. Профайл → "Бүртгэлээ хамгаалах" дээр имэйл, нууц үг холбоно. Өөр утсанд "Нэвтрэх" дарна |
| Офлайн ахиц | Энэ утсанд анх холбогдоход офлайн ахиц нэг удаа сервер рүү шилжинэ (дээд хязгаар: 1400 RP, 2000 зоос) |
| Rank тоглолт | "Rank тоглолт" товч ижил цолтой тоглогч хайна. Олдвол онлайн 1v1, дүнг сервер хоёр тоглогчид зэрэг тооцно (Elo; K = 24, FT3-д 40) |
| Тоглогч олдохгүй бол | 10 секундийн дараа "Ботой тоглох" сонголт гарна. Бот нь тоглогчийн rating-д тааруулсан, "бот" гэж тэмдэглэгдсэн. Ботыг хожиж зөвхөн 1400 RP (Гарьд) хүртэл ахина |
| AI-тай тоглох | Бэлтгэл: зоос өгнө, rank болон ялалт/ялагдлын бүртгэлд нөлөөлөхгүй |
| Офлайн үеийн тоглолт | Интернэтгүй үед бот ба бэлтгэл тоглолтын дүн утсанд хадгалагдаж (хамгийн ихдээ 20), холбогдохоор илгээгдэнэ |
| Өдрийн шагнал | Сервер Улаанбаатарын цагаар өдөрт нэг удаа олгоно |
| Загвар худалдан авах | `buy_theme`, 100 зоос |
| Хоч | Давтагдашгүй (том жижиг үсэг ялгахгүй), 3–16 тэмдэгт |
| Тэргүүлэгчид | Цолтой (5+ rank тоглолттой) тоглогчдоос эхний 50, мөн таны байр |
| Бүртгэл устгах | Тохиргоо → устгах: сервер дээрх бүртгэл, түүх бүрмөсөн устна (`delete_my_account`) |

### Rank ба цол

| Цол | Үсэг | Rating |
| --- | --- | --- |
| Шинэ бөх | D, D+ | 0+ |
| Начин | C-, C, C+ | 725+ |
| Харцага | B-, B, B+ | 950+ |
| Заан | A-, A, A+ | 1175+ |
| Гарьд | S-, S, S+ | 1400+ |
| Арслан | SS | 1700+ |
| Аварга | U | 1850+ |
| Даян аварга | X | 2000+ |

Эхний 5 rank тоглолт нь байршуулах тоглолт. Энэ хугацаанд цолын оронд "?" харагдана. SQL-ийн `rank_letter()`, `rank_title()`, `title_index()` функцүүд тоглоомын босготой яг ижил.

## 6. Онлайн rank тоглолт хэрхэн ажилладаг вэ

### Тоглогч хайх

- Тоглоом 2 секунд тутамд `find_match(format)` дуудна. Буцаах мөрөнд `id` байвал өрсөлдөгч олдсон гэсэн үг.
- Эхлээд зөвхөн **ижил цолтой** тоглогчтой тааруулна. Хүлээсэн 15 секунд тутамд нэг цолоор өргөжинө. 20 секундээс хойш өөр формат (нэг тоглолт / FT3) сонгосон тоглогчтой ч тааруулна, энэ үед удаан хүлээсэн тоглогчийн формат мөрдөгдөнө.
- Хайхаа больсон тоглогчийн бичлэг 15 секундийн дараа дарааллаас хасагдана. Цуцлахад `cancel_queue()`.

### Тоглолт эхлэх

1. Хоёр утас `match:<id>` сувагт нэгдэж, `ping_match`-аар "би холбогдсон" гэж мэдэгдэнэ.
2. Хоёр тал бие биенээ сонссоны дараа 3 секундийн тоолуур эхэлнэ.
3. Блокийн дараалал `seed + тоглолтын дугаар`-аас үүсэх тул хоёр тоглогчид ижил байна.

Өрсөлдөгч огт холбогдоогүй бол 12–14 секундийн дараа тоглолт дүнгүйгээр цуцлагдана (`claim_abandoned`). Өөрийн Realtime холболт нээгдээгүй бол тоглогч `leave_unstarted`-аар дүнгүйгээр гарна.

### Тоглолтын үеэр

| Мессеж | Агуулга |
| --- | --- |
| `hi` | Холбогдсон гэдгээ мэдэгдэх, эхлэх дохио (`go`) |
| `s` | Талбарын зураг, унаж буй блок, ирж буй мөрийн тоо, статистик, сүүлийн 8 дайралт, ялагдсан эсэх |
| `over`, `bye` | "Серверээс дүнгээ асуу" гэсэн дохио |

- Дайралт бүр дугаартай бөгөөд `s` мессеж бүрд сүүлийн 8 нь давтагдана. Тиймээс мессеж алдагдсан ч дайралт алдагдахгүй, давхар тоологдохгүй.
- **Оноог зөвхөн сервер шийднэ.** Овоолго нь дээд захад хүрсэн тоглогч өөрөө `report_online_game(match, game)` дуудаж, оноо өрсөлдөгчид очно. Зөвхөн ялагдагч мэдээлдэг тул луйварчин зөвхөн өөртөө хор хийнэ. Хоёулаа зэрэг ялагдвал эхэлж ирсэн мэдээлэл тооцогдоно.
- Утас бүр 4 секунд тутамд `ping_match` дуудаж серверийн мөрийг уншина. Оноо, дараагийн тоглолт, цувралын төгсгөлийг тэр мөрөөс мэднэ.
- Өрсөлдөгч 30 секунд чимээгүй болбол `claim_abandoned`-аар цувралыг авна.
- Онлайн тоглолтыг түр зогсоох боломжгүй. Түр зогсоох товч "Бууж өгөх үү?" гэж асууна (`forfeit_online`, ялагдалд тооцогдоно).
- Чадвар (удаашруулах, бамбай, цэвэрлэх) зөвхөн AI-тай бэлтгэл тоглолтод ажиллана.

## 7. Мэдээллийн сан

- `profiles`: хоч, дүрс, rating, ялалт/ялагдал, зоос, загвар, өдрийн дараалал. Бүх хүн уншиж болно, хэн ч шууд бичиж чадахгүй.
- `matches`: тоглолтын түүх (`ai`, `bot`, `online`). Тоглогч зөвхөн өөрийнхөө түүхийг харна.
- `leaderboard` (view): цолтой тоглогчид, байрлалтайгаа.
- `match_queue`: тоглогч хайж буй хүмүүс. `online_matches`: онлайн цувралууд (оноо, seed, төлөв).

Функцүүд: `get_my_profile`, `my_position`, `set_profile`, `report_match`, `claim_daily`, `buy_theme`, `import_local`, `delete_my_account`, `find_match`, `cancel_queue`, `ping_match`, `report_online_game`, `claim_abandoned`, `leave_unstarted`, `forfeit_online`.

## 8. Шалгах

- `supabase/tests/run_local.sh`: хоёр migration-ийг энгийн Postgres дээр ажиллуулж бүх функцийг шалгана.
- `supabase/tests/e2e_online.py`: хоёр хөтчийн тоглогчийг жинхэнэ SQL функцүүдтэй холбож, Realtime-ийг орлуулсан дамжуулагчаар бүтэн тоглолт хийлгэнэ (хайх, эхлэх, дайралт, FT3, зэрэг ялагдах, бууж өгөх, холболт тасрах, өрсөлдөгч ирэхгүй байх, бот, мессежийн 50% алдагдал). Ажиллуулах зааврыг файлын эхэнд бичсэн.

## 9. Анхаарах

- **Луйвар:** онлайн тоглолтод оноог ялагдагч мэдээлдэг ч дайралтын тоог утас бүр өөрөө тооцдог. Өөрчилсөн аппаар хэт их дайралт илгээх боломжтой хэвээр. Тоглогч олширвол replay хадгалж шалгах эсвэл серверт тоглолтыг дахин тооцоолох хэрэгтэй болно.
- **Бот ба бэлтгэлийн дүн:** утас өөрөө мэдээлдэг. Сервер оноог шалгаж, 10 секундэд нэгээс олон мэдээллийг хүлээж авдаггүй, ботоор 1400-аас дээш ахиулдаггүй. Зоосыг мөнгөөр зардаг болбол бэлтгэл тоглолтын зоосонд өдрийн хязгаар тавих хэрэгтэй.
- **Тоглолтоос гарсан тоглогч:** апп хаагдсан бол өрсөлдөгч 30 секундийн дараа цувралыг авна. Дахин "Rank тоглолт" дарсан тоглогчийн дуусаагүй хуучин цуврал ялагдалд тооцогдоно.
- **Зардал:** Realtime мессеж болон зэрэг холбогдох тоглогчийн тоо Supabase-ийн багцаар хязгаарлагддаг. Тоглогч олширвол Usage хуудсаа хянаж, шаардлагатай бол багцаа ахиулна.
- Тоглоом гаргахын өмнө нууцлалын бодлогын хуудас, мөн Google Play-д бүртгэл устгах заавар (тоглоомд аль хэдийн бий) хэрэгтэй.
