# Neon Duel: Supabase холболт

Тоглоом Supabase-гүйгээр бүрэн офлайн ажиллана. Доорх тохиргоог хийсний дараа онлайн болно: бүртгэл, сервер дээр тооцогдох rank, тэргүүлэгчдийн жагсаалт. Онлайн 1v1 тоглолтын серверийн хэсэг бэлэн, тоглоомын талын холболтыг нь дараагийн алхамд хийнэ.

## 1. Project үүсгэх

1. https://supabase.com дээр **New project** үүсгэнэ. Region-оо Монголд ойр **Northeast Asia (Seoul)** эсвэл **Tokyo** гэж сонгоно.
2. **SQL Editor → New query** нээгээд `supabase/migrations/20261113000000_neon_duel_init.sql` файлын агуулгыг бүхэлд нь хуулж **Run** дарна. Supabase CLI ашигладаг бол `supabase db push` хийнэ. Скриптийг дахин ажиллуулахад асуудалгүй.

## 2. Нэвтрэлтийн тохиргоо (Authentication)

- **Sign In / Providers → Anonymous sign-ins**-ийг асаана. Тоглоом анх нээгдэхэд тоглогч бүрт автоматаар зочин бүртгэл үүсгэдэг.
- **Email** provider асаалттай байх ёстой. Тоглогч "Бүртгэлээ хамгаалах" дарж имэйл, нууц үгээ холбоход хэрэглэгдэнэ.
  - **Confirm email** асаалттай бол баталгаажуулах имэйл очно. Тоглогч линк дээр дарсны дараа бүртгэл хамгаалагдана.
  - Туршилтын үед унтрааж болно. Гэхдээ тоглоом гаргахын өмнө асаана.
- Зочин бүртгэлийг урвуулан ашиглахаас сэргийлэхийн тулд хожим **Attack Protection**-оос CAPTCHA (Turnstile) асаахыг зөвлөж байна.

## 3. Тоглоомд түлхүүрээ оруулах

**Project Settings → API** хэсгээс **Project URL** болон **anon (publishable) key**-г авна. Anon key-г тоглоомд оруулахад аюулгүй: бүх хүснэгт RLS-ээр хамгаалагдсан, оноо болон зоосыг зөвхөн серверийн функцүүд өөрчилдөг.

Хоёр аргаар оруулж болно:

- **APK-д (санал болгох):** GitHub repo → **Settings → Secrets and variables → Actions** хэсэгт `SUPABASE_URL` болон `SUPABASE_ANON_KEY` гэсэн хоёр secret нэмнэ. Дараагийн APK build автоматаар онлайн хувилбар болно. Secret байхгүй бол офлайн хувилбар гарна.
- **Вэб хувилбарт:** `index.html` доторх `<script id="neon-config">` блокийг бөглөнө:
  ```html
  <script id="neon-config" type="application/json">{"supabaseUrl":"https://xxxx.supabase.co","supabaseAnonKey":"eyJ..."}</script>
  ```

Өөрийн домэйн (custom domain) ашиглавал `index.html`-ийн толгой дахь `Content-Security-Policy`-ийн `connect-src`-д тэр домэйноо нэмнэ. Одоо `https://*.supabase.co wss://*.supabase.co` байгаа.

## 4. Онлайн болоход юу ажиллах вэ

| Хэсэг | Хэрхэн |
| --- | --- |
| Бүртгэл | Анх нээхэд зочин бүртгэл үүснэ. Профайл → "Бүртгэлээ хамгаалах" дээр имэйл, нууц үг холбоно. Өөр утсанд "Нэвтрэх" дарна |
| Офлайн ахиц | Энэ утсанд анх холбогдоход офлайн ахиц нэг удаа сервер рүү шилжинэ (дээд хязгаар: 1400 RP, 2000 зоос) |
| Rank, зоос | Тоглолт бүрийн дүнг сервер `report_match` функцээр дахин тооцно (Elo; K = 24, FT3-д 40). Сервер дээрх тоо үнэн гэж тооцогдоно |
| Офлайн үеийн тоглолт | Интернэтгүй үед дүн утсанд хадгалагдаж (хамгийн ихдээ 20), холбогдохоор илгээгдэнэ |
| Өдрийн шагнал | Сервер Улаанбаатарын цагаар өдөрт нэг удаа олгоно |
| Загвар худалдан авах | `buy_theme`, 100 зоос |
| Хоч | Давтагдашгүй (том жижиг үсэг ялгахгүй), 3–16 тэмдэгт |
| Тэргүүлэгчид | Цолтой (5+ тоглолттой) тоглогчдоос эхний 50, мөн таны байр |
| Бүртгэл устгах | Тохиргоо → устгах: сервер дээрх бүртгэл, түүх бүрмөсөн устна (`delete_my_account`) |

### Rank ба цол

| Цол | Үсэг | Rating |
| --- | --- | --- |
| Шинэ бөх | D, D+ | 0+ |
| Начин | C-, C, C+ | 725+ |
| Харцага | B-, B, B+ | 950+ |
| Заан | A-, A, A+ | 1175+ |
| Гарьд | S-, S, S+ | 1400+ |
| Арслан | SS | 1700+ |
| Аварга | U | 1850+ |

Эхний 5 тоглолт нь байршуулах тоглолт. Энэ хугацаанд цолын оронд "?" харагдана. SQL-ийн `rank_letter()` болон `rank_title()` функцүүд тоглоомын босготой яг ижил.

## 5. Мэдээллийн сан

- `profiles`: хоч, дүрс, rating, ялалт/ялагдал, зоос, загвар, өдрийн дараалал. Бүх хүн уншиж болно, хэн ч шууд бичиж чадахгүй.
- `matches`: тоглолтын түүх. Тоглогч зөвхөн өөрийнхөө түүхийг харна.
- `leaderboard` (view): цолтой тоглогчид, байрлалтайгаа.
- `match_queue`, `online_matches`: онлайн 1v1-д зориулагдсан.

Тоглоомын ашигладаг функцүүд: `get_my_profile`, `my_position`, `set_profile`, `report_match`, `claim_daily`, `buy_theme`, `import_local`, `delete_my_account`, `find_match`, `cancel_queue`, `ping_match`, `report_online_game`, `claim_abandoned`, `forfeit_online`.

Шалгах: `supabase/tests/run_local.sh` нь migration-ийг энгийн Postgres дээр Supabase-ийн оронд ажиллах хялбаршуулсан орлуулагчтай ажиллуулж, бүх функцийг шалгадаг.

## 6. Дараагийн алхам: онлайн 1v1

Серверийн хэсэг бэлэн. Тоглоомд дараах урсгалыг нэмнэ:

1. **Тоглогч хайх:** "Хурдан хайлт" дарахад 2 секунд тутамд `find_match(format)` дуудна. Буцаах утга `null` бол хүлээсээр байна. Rating-ийн зөрүүний зөвшөөрөгдөх хязгаар 150-аас эхэлж, хүлээсэн секунд тутам 10-аар өснө. Хүлээж буй тоглогч `online_matches` хүснэгтийн Realtime өөрчлөлтийг сонсож болно. Цуцлах бол `cancel_queue()`.
2. **Тоглолтын суваг:** хоёр тоглогч Realtime Broadcast сувагт (`match:<id>`) нэгдэнэ. Блокийн дараалал `online_matches.seed + game` гэсэн seed-ээр үүсэх тул хоёуланд ижил байна.
3. **Мессежүүд:**
   - `ready` / `start {game}`: хоёулаа бэлэн болоход 3 секундийн тоолуур эхэлнэ.
   - `board {rows, piece, hold, queue, pending}`: секундэд 8–10 удаа илгээнэ, өрсөлдөгчийн жижиг талбарт харуулна.
   - `attack {id, rows, hole}`: илгээгч өөрийн ирж буй мөрийг эхлээд цуцлаад, үлдсэнийг нь илгээнэ. Хүлээн авагч одоогийнх шигээ дараалалд хийж, хүлээлттэйгээр оруулна.
   - `topout {game}`: ялагдсан тоглогч илгээгээд `report_online_game(id)` дуудна. Зөвхөн ялагдагч мэдээлдэг тул луйварчин зөвхөн өөртөө хор хийнэ.
4. **Холболт тасрах:** 10 секунд тутам `ping_match(id)` дуудна. Өрсөлдөгч 30 секунд чимээгүй байвал `claim_abandoned(id)` дуудаж ялалт авна. Тоглолтоос гарвал `forfeit_online(id)`.
5. **Дуусах:** FT3-д 3 хожсон эсвэл нэг тоглолтод хожсон үед сервер хоёр тоглогчийн Elo, зоос, түүхийг нэг дор шинэчилнэ. Тоглоомын `Cloud` объектод `findMatch`, `cancelQueue`, `pingMatch`, `reportOnlineGame`, `claimAbandoned`, `forfeitOnline` гэсэн бэлэн функцүүд байгаа.

### Анхаарах

- AI болон ботын эсрэг тоглолтын дүнг утас өөрөө мэдээлдэг. Сервер оноог шалгаж, 10 секундэд нэгээс олон мэдээллийг хүлээж авдаггүй. Гэхдээ өөрчилсөн аппаар оноо "тариалах" боломжтой хэвээр. Онлайн 1v1 гарсны дараа rank-ийг зөвхөн онлайн тоглолтоор тооцох, эсвэл AI болон онлайн rank-ийг тусад нь хөтлөх эсэхийг шийдэх хэрэгтэй.
- Тоглоом гаргахын өмнө нууцлалын бодлогын хуудас, мөн Google Play-д бүртгэл устгах заавар (тоглоомд аль хэдийн бий) хэрэгтэй.
