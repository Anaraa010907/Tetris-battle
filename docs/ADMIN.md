# Admin эрх ба зөвлөгч

Admin эрхээр нэвтэрсэн хүнд **бэлтгэл тоглолтод** (NOVA AI-тай) зөвлөгч гарна:

- Самбар дээр одоогийн блокийг хаана тавих нь хамгийн ашигтайг алтан хүрээгээр зурна.
- Эхлээд хадгалах нь дээр бол хүрээ цэнхэр, тасархай болж, «Хадгалах» товч гэрэлтэнэ.
- Баруун доод буланд юу гарахыг (жишээ нь `T-SPIN DOUBLE +4`, `QUAD +5`, `2 COMBO`) болон дарах товчнуудыг
  дэлгэцийн товчтой ижил тэмдгээр харуулна: `← →` хажуу тийш, `↺ ↻` эргүүлэх, `↓` доош, `⤓` унагах.

Зөвлөгч rank (боттой ч, хүнтэй ч), онлайн болон найзтай тоглолтод **хэзээ ч гарахгүй**: өөр хүний эсрэг
шударга бус туслах болохоос сэргийлсэн.

## Нэвтрэх

1. Тохиргоо (⚙) нээнэ.
2. «Тохиргоо» гэсэн гарчиг дээр 3 секундын дотор 5 удаа дарна.
3. Нэр ба кодоо оруулна. 5 удаа буруу оруулбал 1 минут түгжигдэнэ.

Нэвтэрсний дараа Тохиргоонд «Зөвлөгч: Асаалттай/Унтраалттай» болон «Admin-аас гарах» товч гарна.
Admin эрх зөвхөн тухайн утсанд хадгалагдана (профайлд ороогүй, сервер рүү явахгүй).

## Код хаана хадгалагдах вэ

Код өөрөө repo-д байхгүй. `src/js/44-coach.js` дотор зөвхөн `sha256('khan-coach-v1|' + нэр + '|' + код)` гэсэн
hash байна. Нэр эсвэл кодоо солих бол шинэ hash-ыг ингэж гаргаад `ADMIN_HASH`-д тавина:

    python3 -c "import hashlib;print(hashlib.sha256(b'khan-coach-v1|ШИНЭ_НЭР|ШИНЭ_КОД').hexdigest())"

Анхаар: тоглоом бүхэлдээ утсан дээр ажилладаг тул энэ нь жинхэнэ хамгаалалт биш, зүгээр л нуусан хаалга.
Гэхдээ зөвлөгч зөвхөн бэлтгэл тоглолтод ажилладаг тул хэн нэг нь тайлсан ч rank, онлайн тоглолтод нөлөөлөхгүй.

## Хэрхэн бодож шийддэг вэ

Блок очиж болох бүх байрлалыг жинхэнэ хөдөлгөөнөөр (хажуу, доош, SRS kick-тэй эргүүлэлт) хайдаг тул доогуур
шургуулах (tuck) болон T-spin-ийг олно. Байрлал бүрийг довтолгоо (T-spin, quad, combo, B2B, бүтэн цэвэрлэгээ)
болон үлдэх самбарын байдлаар (нүх, тэгш байдал, өндөр, quad-д зориулсан нэг худаг, бэлэн T-spin нүх) үнэлээд
дараагийн нэг блокийг ч тооцдог. Самбар өндөр болох эсвэл хог мөр ирж байвал эхлээд цэвэрлэж амьд үлдэхийг
чухалчилна. 180° эргүүлэлт утсан дээр товчгүй тул түүнийг хэзээ ч санал болгодоггүй.
