# Neon Duel

1v1 тетрис тулаант тоглоом. Утсанд зориулагдсан, монгол болон англи хэлтэй.

## Тоглох

`index.html`-ийг хөтөч дээр нээгээд тоглоно. Сервер шаардлагагүй.

### Удирдлага

- Удирдлага дэлгэцийн хаана ч ажиллана, доор товчнууд ч бас бий:
  - Товших: блок баруун тийш эргэнэ (↺ товч зүүн тийш эргүүлнэ)
  - Хуруугаа зүүн, баруун тийш гулсуулах: блок хурууг дагаж хөдөлнө
  - Доош аажуухан гулсуулах: блок хурууг дагаж буна
  - Доош хурдан шудрах: блок шууд унана
  - Дээш шудрах эсвэл ХАДГАЛАХ хайрцаг дээр товших: блокоо хадгална (нэг блокт нэг удаа)
- Компьютер дээр: ← → хөдөлгөнө; ↑ эсвэл X баруун тийш, Z эсвэл Ctrl зүүн тийш, A 180° эргүүлнэ; ↓ зөөлөн, Space шууд унагана; C эсвэл Shift хадгална; P түр зогсооно; Esc буцна

### Дүрэм (TETR.IO Tetra League-ийн механик)

- SRS эргэлт ба kick, 7-bag. Хоёр тоглогчид ижил дарааллаар блок ирнэ, дараагийн 5 блок харагдана
- Блок газарт хүрснээс хойш 0.5 секундын дараа бэхэлгддэг. Хөдөлгөх, эргүүлэхэд хугацаа шинэчлэгдэх ба хамгийн ихдээ 15 удаа
- Дайралт:
  - 2, 3, 4 мөр (DOUBLE, TRIPLE, QUAD) → 1, 2, 4 саадтай мөр
  - T-spin-ээр 1, 2, 3 мөр → 2, 4, 6. T-spin mini-ээр 2 мөр → 1
  - B2B: QUAD эсвэл T-spin-ийг дараалуулбал +1 (урт цувралд +2, +3…)
  - COMBO: дараалсан блок бүрээр мөр цэвэрлэвэл дайралт 25% тутамд өснө
  - ALL CLEAR: талбараа бүрэн цэвэрлэвэл +10
- Ирж буй саадтай мөр талбарын хажуугийн хэмжүүрт харагдана: улбар шар нь ирж яваа, улаан нь бэлэн болсон. Мөр цэвэрлэвэл эхлээд түүнийг цуцална. Үгүй бол мөр цэвэрлээгүй блок тавих үед доороос орж ирнэ (нэг блокт хамгийн ихдээ 8 мөр)
- Улаан X: дараагийн блок гарах газар хаагдах дөхсөн гэсэн үг
- Статистик: PPS (секундэд тавьсан блок), APM (минутад илгээсэн дайралт), VS ((дайралт + цэвэрлэсэн саадтай мөр) / секунд × 100)

### Тоглолт, rank

- AI-ийн түвшин: Хялбар, Дунд, Хүнд. Хүнд түвшний AI нэг блокоор урьдчилан тооцоолж, QUAD хийхийн тулд худаг үлдээдэг
- Тоглолтын формат (Тохиргоо): нэг тоглолт эсвэл FT3 (3 хожсон нь ялна). FT3-д rank зөвхөн цувралын эцэст өөрчлөгдөнө
- Rank: TETR.IO шиг D-ээс X хүртэлх үсэг, бөхийн цолоор бүлэглэгдэнэ: Шинэ бөх (D), Начин (C), Харцага (B), Заан (A), Гарьд (S), Арслан (SS), Аварга (U), Даян аварга (X). Эхний 5 тоглолт байршуулах тоглолт тул "?" гэж харагдана. Өөрөөсөө өндөр rating-тэй өрсөлдөгчийг хожвол илүү их RP авна
- Цол ахих, буурахад дүнгийн дэлгэц дээр мэдэгдэл гарна. Профайл дээр дараагийн цол хүртэлх явц, цолын шат, тэргүүлэгчдийн жагсаалт харагдана
- Чадвар (удаашруулах, бамбай, цэвэрлэх) анхдагчаар унтраалттай, Тохиргооноос асаана

### Онлайн (Supabase)

Тохиргоогүй бол тоглоом бүрэн офлайн ажиллана: мэдээлэл утсанд хадгалагдана, "Хурдан хайлт" нь ботуудтай тоглуулна. Supabase холбосны дараа зочин бүртгэл, серверт тооцогдох rank ба зоос, тэргүүлэгчдийн жагсаалт, имэйлээр бүртгэл хамгаалах, бүртгэл устгах боломжтой болно. Тохируулах заавар болон онлайн 1v1-ийн төлөвлөгөөг [docs/SUPABASE.md](docs/SUPABASE.md)-ээс үзнэ үү.

## Файлууд

| Файл | Юу байгаа |
| --- | --- |
| `index.html` | Тоглоом бүхэлдээ: HTML, CSS, JS, дуу, зураг |
| `android/` | Тоглоомыг WebView-д ачаалдаг Android апп |
| `.github/workflows/android-apk.yml` | Debug APK бүтээх workflow (Supabase secret байвал онлайн хувилбар) |
| `supabase/migrations/` | Мэдээллийн сангийн бүтэц, RLS, серверийн функцүүд |
| `supabase/tests/` | Migration-ийг энгийн Postgres дээр шалгах скрипт (`run_local.sh`) |
| `docs/SUPABASE.md` | Supabase тохируулах заавар |

## Android APK

GitHub-ийн **Actions → Build Android APK → Run workflow** дээр гараар ажиллуулна. Workflow `index.html`-ийг аппын assets руу хуулж, debug APK бүтээгээд artifact болгон хадгална.

## Дараагийн алхам

- Supabase project үүсгээд `docs/SUPABASE.md`-ийн дагуу холбох
- Онлайн 1v1: тоглогч хайх, Realtime-ээр тоглолтын мэдээлэл солилцох (серверийн хэсэг бэлэн)
