# Neon Duel

1v1 тетрис тулаант тоглоом. Утсанд зориулагдсан, монгол болон англи хэлтэй.

## Тоглох

`index.html`-ийг хөтөч дээр нээгээд тоглоно. Сервер шаардлагагүй.

- Блок эргүүлэх: талбар дээр товших эсвэл ↻ товч
- Хөдөлгөх: зүүн, баруун тийш шударах эсвэл ← → товч
- Буулгах: доош шударвал зөөлөн, дээш шударвал шууд унана
- 2, 3, 4 мөр нэг дор цэвэрлэвэл өрсөлдөгч рүү 1, 2, 4 саадтай мөр илгээнэ
- 3 мөр тутамд нэг чадвар авна (хамгийн ихдээ 2):
  - Удаашруулах: өрсөлдөгчийг 5 секунд удаашруулна
  - Бамбай: ирэх нэг дайралтыг хаана
  - Цэвэрлэх: хамгийн доод мөрийг арилгана
- Компьютер дээр: ← → ↑ ↓ товчоор хөдөлгөнө, Space дарвал шууд унана, P дарвал түр зогсоно, Esc дарвал буцна

Одоогоор офлайн хувилбар. Тоглогчийн мэдээлэл, оноо, зоос зөвхөн тухайн төхөөрөмжид хадгалагдана. "Хурдан хайлт" цэс бодит хүн биш, өөр өөр хурдтай ботуудтай тоглуулдаг.

## Файлууд

| Файл | Юу байгаа |
| --- | --- |
| `index.html` | Тоглоом бүхэлдээ: HTML, CSS, JS, дуу, зураг |
| `android/` | Тоглоомыг WebView-д ачаалдаг Android апп |
| `.github/workflows/android-apk.yml` | Debug APK бүтээх workflow |

## Android APK

GitHub-ийн **Actions → Build Android APK → Run workflow** дээр гараар ажиллуулна. Workflow `index.html`-ийг аппын assets руу хуулж, debug APK бүтээгээд artifact болгон хадгална.

## Дараагийн алхам

- Supabase-ээр жинхэнэ бүртгэл, онлайн тоглогч хайх, rank хийх
- Онлайн болгохын өмнө `index.html`-ийн толгой дахь `Content-Security-Policy`-д Supabase-ийн хаягийг `connect-src`-д нэмэх (одоо `'none'` байгаа)
