# Khan Blocks

> Өмнөх ажлын нэр: Neon Duel. Нэр сонгосон шалтгаан: [docs/NAME.md](docs/NAME.md). Нэр нэг газраас ирдэг: `src/i18n/45-brand.json`-ийн `brandName` (build нь `@@brand@@`-ийг, тоглоом `{@brandName}`-ийг түүгээр солино).

Унаж буй блокоор мөр цэвэрлэж, өрсөлдөгчөө шахдаг 1v1 тулаант тоглоом. Утсанд зориулагдсан, монгол болон англи хэлтэй.

## Тоглох

`index.html`-ийг хөтөч дээр нээгээд тоглоно. Сервер шаардлагагүй.

### Удирдлага

- Удирдлага дэлгэцийн хаана ч ажиллана, доор товчнууд ч бас бий:
  - Товших: блок баруун тийш эргэнэ (↺ товч зүүн тийш эргүүлнэ)
  - Хуруугаа зүүн, баруун тийш гулсуулах: блок хурууг дагаж хөдөлнө
  - Доош аажуухан гулсуулах: блок хурууг дагаж буна
  - Доош хурдан шудрах: блок шууд унана
  - Дээш шудрах эсвэл ХАДГАЛАХ хайрцаг дээр товших: блокоо хадгална (нэг блокт нэг удаа)
- Компьютер дээр: ← → хөдөлгөнө; ↑ эсвэл X баруун тийш, Z эсвэл Ctrl зүүн тийш, A 180° эргүүлнэ; ↓ зөөлөн, Space шууд унагана; C эсвэл Shift хадгална; P түр зогсооно; Esc буцна

### Дүрэм

- SRS эргэлт ба kick, 7-bag. Хоёр тоглогчид ижил дарааллаар блок ирнэ, дараагийн 5 блок харагдана
- Блок газарт хүрснээс хойш 0.5 секундын дараа бэхэлгддэг. Хөдөлгөх, эргүүлэхэд хугацаа шинэчлэгдэх ба хамгийн ихдээ 15 удаа
- Дайралт:
  - 2, 3, 4 мөр (DOUBLE, TRIPLE, QUAD) → 1, 2, 4 саадтай мөр
  - T-spin-ээр 1, 2, 3 мөр → 2, 4, 6. T-spin mini-ээр 2 мөр → 1
  - B2B: QUAD эсвэл T-spin-ийг дараалуулбал +1 (урт цувралд +2, +3…)
  - COMBO: дараалсан блок бүрээр мөр цэвэрлэвэл дайралт 25% тутамд өснө
  - ALL CLEAR: талбараа бүрэн цэвэрлэвэл +10
- Ирж буй саадтай мөр талбарын хажуугийн хэмжүүрт харагдана: улбар шар нь ирж яваа, улаан нь бэлэн болсон. Мөр цэвэрлэвэл эхлээд түүнийг цуцална. Үгүй бол мөр цэвэрлээгүй блок тавих үед доороос орж ирнэ (нэг блокт хамгийн ихдээ 8 мөр)
- Улаан X: дараагийн блок гарах газар хаагдах дөхсөн гэсэн үг
- Статистик: PPS (секундэд тавьсан блок), APM (минутад илгээсэн дайралт), VS ((дайралт + цэвэрлэсэн саадтай мөр) / секунд × 100)

### Тоглолтын горим, rank

- **AI-тай тоглох (бэлтгэл):** Хялбар, Дунд, Хүнд түвшин. Зоос өгнө, rank-д нөлөөлөхгүй. Чадвар (удаашруулах, бамбай, цэвэрлэх) зөвхөн энд ажиллана, Тохиргооноос асаана
- **Rank тоглолт:** ижил цолтой тоглогчтой онлайн 1v1. Хожвол RP нэмэгдэж, ялагдвал хасагдана. Тоглогч олдохгүй эсвэл сервер холбогдоогүй үед өөрийн түвшний, "бот" гэж тэмдэглэгдсэн ботой тоглоно
- Тоглолтын формат (Тохиргоо): нэг тоглолт эсвэл FT3 (3 хожсон нь ялна). FT3-д rank зөвхөн цувралын эцэст өөрчлөгдөнө
- Rank: D-ээс X хүртэлх үсэг, хааны цэргийн цолоор бүлэглэгдэнэ: Цэрэг (D), Аравт (C, 10 цэргийн дарга), Зуут (B, 100), Мянгат (A, 1 000), Түмэн (S, 10 000), Жанжин (SS), Хаан (U), Их хаан (X). Цол бүр өөрийн тэмдэгтэй (сум, нум, бамбай, дуулга, туг, титэм); нэр, өнгө, тэмдэг нь `src/js/11-ranks.js`-ийн `TITLES` хүснэгтээс. Эхний 5 rank тоглолт байршуулах тоглолт тул "?" гэж харагдана. Өөрөөсөө өндөр rating-тэй өрсөлдөгчийг хожвол илүү их RP авна
- Онлайн үед ботыг хожиж зөвхөн Түмэн (1400 RP) хүртэл ахина. Түүнээс дээш цол зөвхөн жинхэнэ тоглогчийг хожиж ахина
- Цол ахих, буурахад дүнгийн дэлгэц дээр мэдэгдэл гарна. Профайл дээр дараагийн цол хүртэлх явц, цолын шат, тэргүүлэгчдийн жагсаалт харагдана
- Онлайн тоглолтыг түр зогсоох боломжгүй. Түр зогсоох товч бууж өгөх эсэхийг асууна

### Блокийн загвар

- Үндсэн загвар «Хээ угалз»: монгол хээ угалзаас сэдэвлэсэн, шаталсан булантай сийлбэртэй блок. Блок бүр өнгөнөөс гадна өөрийн хээтэй (= ○ ◇ угалз ∧ • □), тиймээс өнгө ялгахад бэрхшээлтэй хүн ч ялгана. Саадтай мөр нь ширдэг шиг оёдолтой
- Дэлгүүрт: «Туйлын туяа» (гэрэлтэх неон хүрээ), «Говийн үдэш» (эрдэнийн чулуу шиг зүсэлт), тус бүр 100 зоос
- Загвар бүр `src/js/59-skins.js`-ийн `SKINS` жагсаалтад байна (өнгө, блокийн хэв маяг, талбайн өнгө); шинэ загвар нэмэхэд тэнд нэг мөр нэмээд, серверийн `buy_theme`-ийг шинэ migration-оор өргөтгөнө (одоо 0–2 id-г л зөвшөөрдөг)

### Онлайн (Supabase)

Тохиргоогүй бол тоглоом бүрэн офлайн ажиллана: мэдээлэл утсанд хадгалагдана, "Rank тоглолт" нь ботуудтай тоглуулна. Supabase холбосны дараа зочин бүртгэл, серверт тооцогдох rank ба зоос, ижил цолтой тоглогчтой онлайн тоглолт, тэргүүлэгчдийн жагсаалт, имэйлээр бүртгэл хамгаалах, бүртгэл устгах боломжтой болно. Тохируулах заавар болон онлайн тоглолтын ажиллах зарчмыг [docs/SUPABASE.md](docs/SUPABASE.md)-ээс үзнэ үү.

## Файлууд

| Файл | Юу байгаа |
| --- | --- |
| `src/` | Тоглоомын эх код: `js/`, `css/`, `i18n/` (орчуулга), `body.html`, `assets/` (фонт, зураг, дуу) |
| `tools/build.py` | `src/`-ээс `index.html`-ийг бүтээнэ (`--check` нь шинэчлэгдсэн эсэхийг шалгана) |
| `index.html` | Бүтээгдсэн тоглоом (гараар засахгүй) |
| `android/` | Тоглоомыг WebView-д ачаалдаг Android апп |
| `.github/workflows/android-apk.yml` | Debug APK бүтээх workflow (Supabase secret байвал онлайн хувилбар) |
| `supabase/migrations/` | Мэдээллийн сангийн бүтэц, RLS, серверийн функцүүд |
| `supabase/tests/` | SQL тест, хоёр тоглогчийн онлайн тоглолтын туршилт |
| `tests/` | Хөтөч дээрх тоглоомын тест (`game_test.py`), бүх тестийг ажиллуулах `run.sh` |
| `docs/SUPABASE.md` | Supabase тохируулах заавар |
| `CLAUDE.md` | Код дээр ажиллах дүрэм |

Өөрчлөлт хийхдээ `src/` доторх файлыг засаад `python3 tools/build.py` ажиллуулж, `tests/run.sh`-ээр шалгана.

## Android APK

GitHub-ийн **Actions → Build Android APK → Run workflow** дээр гараар ажиллуулна. Workflow `index.html`-ийг аппын assets руу хуулж, debug APK бүтээгээд artifact болгон хадгална.
